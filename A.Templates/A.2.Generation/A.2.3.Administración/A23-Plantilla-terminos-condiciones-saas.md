# Plantilla de Generación de Términos y Condiciones SaaS - OGA

## OBJETIVO DE LA PLANTILLA
Esta plantilla está diseñada para que un LLM genere términos y condiciones completos y legalmente sólidos para aplicaciones SaaS B2B y B2B2C de OGA, complementarios al contrato principal, aplicables en el marco legal Español/Europeo, con máxima protección para OGA y claridad para los usuarios finales.

## INSTRUCCIONES FUNDAMENTALES PARA EL LLM

### PRINCIPIOS BÁSICOS
1. **PROTECCIÓN INTEGRAL DE OGA**: Todas las cláusulas deben proteger los intereses comerciales y legales de OGA
2. **CUMPLIMIENTO NORMATIVO**: Estricto cumplimiento RGPD, LSSI, Código Civil y normativa de consumo
3. **CLARIDAD PARA USUARIOS**: Lenguaje accesible pero jurídicamente preciso
4. **COBERTURA COMPLETA**: Todos los aspectos de uso del servicio cubiertos
5. **EJECUTABILIDAD**: Términos ejecutables y defendibles ante tribunales

### DIFERENCIA CON EL CONTRATO PRINCIPAL
- **Contrato**: Relación comercial B2B entre OGA y cliente empresarial
- **Términos y Condiciones**: Regulan el uso del servicio por usuarios finales
- **Complementariedad**: Ambos documentos deben ser coherentes y reforzarse mutuamente

### APLICABILIDAD POR MODELO DE NEGOCIO
- **B2B Puro**: Términos para usuarios empresariales
- **B2B2C**: Términos para usuarios finales de clientes empresariales
- **Freemium/Trial**: Términos específicos para usuarios gratuitos
- **Suscripción**: Términos para usuarios de pago
- **Por uso**: Términos para consumo medido
