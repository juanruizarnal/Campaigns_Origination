# PLANTILLA DE MEMORIA DESCRIPTIVA PARA SUBVENCIONES CERVERA I+D

## INSTRUCCIONES PARA LA IA

Esta plantilla está diseñada para generar memorias descriptivas de alta calidad para solicitudes de subvenciones Cervera de I+D. Debe mantener el mismo nivel de detalle técnico, rigor metodológico y exhaustividad que el documento de referencia.

### CRITERIOS DE CALIDAD OBLIGATORIOS:
- **Detalle técnico**: Incluir especificaciones técnicas precisas, metodologías detalladas y justificaciones científicas
- **Rigor metodológico**: Fundamentar todas las decisiones en literatura científica y mejores prácticas
- **Exhaustividad**: Cubrir todos los aspectos requeridos con el nivel de profundidad del documento original
- **Coherencia**: Mantener consistencia entre todas las secciones del documento
- **Cuantificación**: Incluir datos numéricos específicos, presupuestos detallados y métricas concretas

### ESTRUCTURA OBLIGATORIA:
Seguir exactamente la estructura de secciones indicada, respetando la numeración y jerarquía.
